# Rule-Based Chatbot

## Description

This project is a simple Rule-Based Chatbot developed using Python and Flask.

The chatbot responds to user messages based on predefined rules using if-else statements.

## Features

- Greeting responses
- Name identification
- Help command
- Goodbye response
- User-friendly web interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation

### 1. Clone Project

```bash
git clone <repository-url>
```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

### 3. Run Application

```bash
python app.py
```

### 4. Open Browser

```
http://127.0.0.1:5000
```

## Sample Inputs

- Hello
- Hi
- How are you?
- What is your name?
- Help
- Bye

## Sample Output

User: Hello
